# 多通道装置的画法

装置有几个通道（工位），就每个通道都画，不要只画一个再注“其余相同”。每个通道两张图（供气与水蒸气、预热与尾气之类，按工艺任务拆），共用的设备另画一张公用部分图。

## 图号和编号
- 图号：`P&ID-X01` 为装置 X 的公用部分，`P&ID-XC1`、`P&ID-XC2` 为通道 C 的两张图。X 是装置序号，C 是通道序号。
- 位号回路号 4 位：第 1 位装置，第 2 位通道（0 为公用部分），后两位序号，例如 `FIC-1103`。
- 线号主项序号 4 位：前两位是装置加通道，后两位是该通道内连续的序号，例如 `AIR-1101-25-S1`。线号用 4 位、位号也是 4 位时，位号格式要排除物料代号，否则线号会被当成位号：在模型 `conventions.tag_pattern` 里写 `(?!(?:AIR|N2|H2|…)-)[A-Z]{1,4}-\d{4}[A-Z]?`，把本项目用到的物料代号都列进去。
- 总张数、第几张由模型 `sheets` 的顺序决定，各装置方案附图时只附本装置的图，标题栏写“共 N 张”按全集计。

## 公用部分
- 公用设备（空压机、去离子水装置、不间断电源、上位机、PLC）只在公用图里画一次，位号用通道位 0。公用图配一张公用设备表，位号、名称、规格取自模型。
- 公用介质（压缩空气、去离子水）从公用图经跨图连接器分别进入各通道的供气图；干线接第 1 个通道，其余通道在干线上分支，深的分支靠左，线不交叉。
- 通道图里不再画公用设备，用一个虚线框“公用PLC，见 P&ID-X01”表示测控信号的去向，框里不写位号，避免位号重复。

## 做法
1. 先把一个通道做对（模板），再展开成各通道。位号、线号、图号都按通道改写，不要手抄。
2. 版面参数能带通道号的（本项目的单通道版面函数带 `b = 装置×1000 + 通道×100`），直接传参；写死位号的旧版面，用展开脚本：对模板登记记录和版面 spec 里所有字符串做改写（位号、线号、图号、本图内的线和信号线 id），模板记录只用于绘图，不进正式模型。
3. 展开后用脚本对比各通道图：把通道号归一化后，文字和线条应完全相同。有差异就是改写漏了。
4. 同一项目名的 spec 目录（`_PidBot/specs/<项目名>` 和 `_plain`）是共享的。图号改了含义、张数变了，先把旧 json 清掉再 `prep`，否则旧图会混进校验（出现“图面上有、模型里没有”）。新版次建议放在新的 Plant 父目录（`pipeline.json` 的 `parent`），不动上一版的 DWG。

## 常见问题
- 公用图里的表格对象在 DWG 里放在“表格”层，重开核对以前会因此误报失败，现已放行。
- 重开核对遇到含换行的 MText 报 `ArgumentOutOfRange`：引擎 `Entry.cs` 的 `Info()` 截取文字长度时越界，应先做替换再按替换后的长度取，已在本机引擎修正。
