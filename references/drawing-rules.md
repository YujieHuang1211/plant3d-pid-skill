# 图面规则与依据

数值（线宽、断口、箭头、接管、信号线型、图幅）不写在这里，写在制图配置 `assets/profiles/<名字>.json`，转换器、lint、图例、PDF 核对共用同一份。本文只记与配置无关的做法，以及“规则从哪来”。

## 选配置
- `pipeline.json` 的 `profile`：`pip-ref-a3`（新项目，`new_project.py` 写入）或 `legacy-2026-10`（缺省，老项目复跑图面不变）。
- 项目要偏离配置时，用 `profile_overrides` 和 `profile_override_note` 写明（如 `{"psv_upright": ["P&ID-107"]}` 只在 107 图执行安全阀直立）。合并结果落在 `_工作底稿/_profile_effective.json`。
- 客户或合同另有图幅（A1、A2 等）：配置的 `sheet` 里改 `width/height/frame/title_block`，图签模板用 `assets/config/qmz_mkdwt_<图幅>.json`。不要整图缩小后仍按原字高、线距交付。
- 配置里每条依据标了来源（标准 / 客户 / 项目）和是否已对原件核对。标准条款的 PDF 页、印刷页见配置的 `basis`，本地原件路径见 `standards-index.json`；不整本读标准，按条款查。
- 不要写“全面符合 PIP / ISO / ISA”。`pip-ref-a3` 是“参照 PIP PIC001-2018 的项目 A3 配置”，信号线型参照 ISA-5.1-2024 表 10。

## 图张组织
- 一张图一个清楚的工艺任务。仪表挤靠图框、主流程反复折返、多个系统争用注释区时，先评估拆图或典型详图；不要先缩字、缩符号、减间距。拆图后同时生成跨图连接器，两端线号、流向一致（`validate_views.py` 检查图号互指和线号）。
- 禁区：标题栏与修订栏（配置 `sheet.title_block`，A3 为 x>235 且 y<91）里不得有任何内容。

## 对象与连接
- 管嘴落在设备真实外轮廓上：容器外包框不是壁。Vessel Style 半宽约 1.0×比例，封头最低点高出底线约 0.495×比例；卧式容器本体半高 5×比例、直段 |x|≤8×比例，两端椭圆封头到 ±13×比例，封头上的管嘴按椭圆求 y。底口接封头最低点，不接支脚底线；压差取压下口不开在裙座上。
- 管嘴连接类型：`conn` 写 `flange` / `weld` / `thread` / `none`；没确认时按配置（`pip-ref-a3` 不默认加法兰）。管线穿壁到设备内部时，管嘴放壁上，壁内一段用 `noarrow=True` 的短线。
- 线端、阀件、仪表接到符号连接点，用 `attach(style, at, side, rot, scale, mirror)` 取点，不手算。缩放符号时 `scale` 的含义见 `scripts/geometry.py`。
- 安全阀按配置要求直立（`psv_upright`）：不旋转符号凑空间；流向相反时用 spec 的 `mirror: true`（直立镜像），版面不够时改支路或分图。
- 控制回路写清测量、控制功能、最终元件和信号类别（模型 `loops[]`、`signals[].kind`）；线型由信号含义决定（电 / 气动 / 数据），不因“都经过 PLC”统一。主图简化回路时引用典型回路详图。

## 位号、线号、注释
- 线号 `物料代号-主项序号-外径-等级`，贴在线上方（竖线贴左侧），不压符号、位号、设备；线段放不下就加长线或移设备（≥ 线号长度 + 4 mm）。`scripts/autolabel.py` 可给缺号的线补线号并把压到别的图元的线号换到空位（手工位置优先，放不下的在返回值 fail 里列出）。主项序号前两位按系统分组，同一设备的线放同一组。stable 模式下修订删线不强制重编，登记 `retired`。
- 位号：阀门椭圆在阀下方；仪表圈两行（类别 / 回路号）在上方；设备位号下划线。物理对象只有一个主表示，其他图张引用时用 `ref_of`。
- 注释只写读图、连接、操作、安全、供货界面所需的补充信息；原理讲解放配套文件。注释顶边不高于最下一行位号 2 mm 以上，底边离图框 ≥ 5 mm。独立的出料或界区接口按最终打印尺寸看，不因紧邻而像连成总管。
- 措辞：图面、属性、交付文件都不体现 AI 参与，也不写工具与过程、数据文件名、内部问题编号。角色栏未定写“—”，设计单位留空，类别写“设计确认”。

## 仪表取舍
- 画：规格书、技术方案点名要的；联锁、报警、停机判据用到的；操作人员需要现场读数的；安全相关的。
- 同类电参量合并成一个圈，圈外注明含义；“需要时再加”的可选项写进注释，不画。
- 依据只是“工程假设”且无联锁和操作用途的，先列入 `open_points` 请用户确认，确认不要才删，并同步模型、版面、联锁表、设计依据表。
